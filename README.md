# Varad Gursalkar — Portfolio Website

A modern, editorial portfolio website built with **React**, **Tailwind CSS**, and **Node.js/Express**, featuring a luxury dark gold theme, multi-page routing, and 16 deep-dive case studies.

## 🚀 Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React, React Router v6
- **Backend**: Node.js, Express (PDF resume distribution)
- **Deployment**: Static SPA + Express API

## 📌 Features
- **Editorial Design**: Deep Black + Gold/Amber luxury aesthetic with glassmorphism components
- **Experience Timeline**: Career history at Inspacco, Dentsu India (Classic Legends, Emami, Yara International), Ciena, ProAzure, and Venture Technologies
- **Interactive Projects**: Filterable by enterprise client engagements, telecom algorithmic systems, and personal AI/BI platforms
- **16 Deep-Dive Case Studies**:
  - 9 Business & Economics studies (Anthropic IPO, Mastercard, US Healthcare, SVB Banking Crisis, Jio IPO DRHP, Oracle AI, IT Shift, Tata JLR, AI Safety)
  - 7 Political & Geopolitical studies (Farakka Barrage, Israel Elections, Trump Midterms & AI Lobbying, India Voter Rolls, 4F Crisis, US-Saudi Relations, Putin's Arctic Route)
- **Dual Resume Downloads**: Direct static download & `/api/resume` backend endpoint

## 💻 Local Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the Frontend development server**:
   ```bash
   npm run dev
   ```
   > Runs at `http://localhost:5173/`

3. **Start the Backend API**:
   ```bash
   node server.js
   ```
   > Runs at `http://localhost:5000/`

4. **Production Build**:
   ```bash
   npm run build
   ```
